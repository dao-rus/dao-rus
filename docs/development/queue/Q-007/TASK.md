# Q-007. Вече: созыв по подписям

**Уровень риска:** обычное изменение с миграцией. **Deploy:** да, если миграция только
добавляет. Зависит от Q-006.

[Устав](../../../governance/charters/veche.md), п. 4.2 и 4.6.

## Сделать

1. Опрос создаётся в состоянии **«сбор подписей»** и становится открытым для голосования,
   когда набрал порог подписей.
2. **Порог** — доля участников круга, настройка в админке отдельно для соты и для всего ДАО.
   Подпись инициатора в порог не входит.
3. **Срок сбора** — настройка в админке (по умолчанию 14 дней). Не набрал — закрывается как
   «не созван».
4. **Повторное внесение** того же автора после «не созван» — не раньше паузы из настроек.
   Одинаковость вопроса не определять автоматически: пауза действует на любой новый созыв
   этого автора в том же круге.
5. **Подписи открыты:** видно, кто поддержал созыв. Подписать может участник круга с
   заполненным городом; подпись можно снять до созыва.
6. Кнопка «Поддержать созыв» с пояснением: подпись значит «это стоит обсудить всем», а не «я за».
7. После созыва Хранитель публикует в ветку «Вече» (как в Q-006); на стадии сбора — тоже, с
   кнопкой-ссылкой «Поддержать созыв», если маршрут задан.
8. За подпись награды нет.

## Проверка

Тесты: порог считается без подписи инициатора; срок истекает → «не созван»; пауза повторного
внесения; участник вне круга не подписывает; подпись не равна голосу. Typecheck, миграция на
реальной PostgreSQL.
