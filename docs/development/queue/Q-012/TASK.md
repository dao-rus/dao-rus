# Q-012. Вече: пошаговый созыв и понятный раздел

**Уровень риска:** обычное изменение интерфейса. **Deploy:** да. Механику, схему БД, права,
тайну голоса и анонимность автора не менять: только подача. Зависит от Q-006…Q-011.

Основание — аудит раздела 2026-10-10 (консультант) и решение Вана: **созыв — пошаговые
страницы, одна страница = один шаг**. Все тексты — через `interfaceTextFields`.

## 1. Пошаговый созыв `/veche/new`

Без JavaScript-зависимости: каждый шаг — отдельная страница с GET-формой, уже выбранные
значения передаются скрытыми полями. Черновик в базе не хранить. На каждом шаге: номер
(«Шаг 2 из 6»), «Назад», «Далее». Неверный или пропущенный ввод возвращает на свой шаг с
объяснением.

1. **Вопрос.** Заголовок и описание. Подсказка: о чём вопрос и что нужно решить.
2. **Кого касается вопрос?** «Всех участников ДАО» / «Только моего города — <город из профиля>».
   Слова «круг» и «сота» на экране не использовать. Недоступный вариант (порог не настроен)
   не показывать; если доступен один — показать его как факт и кнопку «Далее».
3. **Как голосовать.** «Тайно — никто не увидит, кто как голосовал» / «Открыто — после
   закрытия видно, кто как голосовал». По умолчанию — тайно.
4. **Сколько длится голосование.** «3 дня» / «7 дней» (по умолчанию) / «14 дней» / «Своя
   дата» / «Пока вопрос актуален» с пояснением, как такой опрос закрывается. Поле даты — только
   при «Своя дата».
5. **Ваше имя.** «Показать» (по умолчанию) / «Скрыть» с предупреждением о косвенном раскрытии.
6. **Как созвать и проверка.** Сводка всех выборов со ссылкой «Изменить» на каждый шаг. Ниже —
   доступные пути, каждый своей кнопкой с последствиями:
   - «Собрать подписи» — «Нужно N подписей участников <круга> за D дней; ваша подпись не
     считается. Потом начнётся голосование». N — тот порог, который будет зафиксирован при
     создании (Q-011).
   - «Созвать сразу за X DARUS» — только если путь включён; при нехватке баланса кнопка
     неактивна с текстом «на балансе Y DARUS».
   Создание — тем же серверным путём, что сейчас (`/api/veche`), с прежними проверками.

Если пользователь не может созывать, `/veche/new` объясняет причину одной фразой: заморожено
право созыва (со ссылкой на решение), пауза после «не созван» (до какой даты), созыв ещё не открыт.

**Участник без города (решение Вана, Устав п. 4.1 и 5.1).** Вече для него заблокировано целиком —
ни созыва, ни подписи, ни голоса, ни на уровне города, ни на уровне всего ДАО. Везде, где он
упирается в эту блокировку (кнопка «Созвать вече», `/veche/new`, кнопки подписи и голоса на
странице вопроса), — одна и та же строка: «Вы не указали место жительства — участие в Вече
недоступно. Указать город» со ссылкой на поле города в профиле. Кнопка «Созвать вече» для него
видна, но неактивна. Читать вопросы и итоги он может.

## 2. Главная `/veche`

- Убрать «Governance · Proposal v0.1» и подзаголовок; заголовок «Вече», одна строка о сути.
- Сверху кнопка **«Созвать вече»** → `/veche/new`. Если созыв не открыт ни в одном круге —
  вместо кнопки строка «Созыв вече пока не открыт»; администратору — ссылка на настройки.
- **Убрать старую форму «Создать предложение».** Старые предложения без голосования показать
  внизу свёрнутым блоком «Архив предложений». API `/api/proposals` не удалять.
- Вопросы — группами: «Собирают подписи», «Идёт голосование», «Завершены» (сюда же «не
  созван»). Пустые группы не показывать.
- Карточка вопроса: заголовок-ссылка, статус, кого касается («Всё ДАО» / город), тайно или
  открыто, срок с подписью («подписи до …», «голосование до …»), прогресс подписей «3 из 5»,
  отметка «вы подписали» / «вы проголосовали», автор или «Автор скрыт». Текст вопроса в
  списке не показывать.
- Ссылку «Настройки Вече» для администратора оформить кнопкой в конце страницы.

## 3. Страница вопроса `/veche/[id]`

- Статус крупно; все даты с подписью («Сбор подписей до …», «Голосование до …»).
- Во время сбора подписей не показывать «Проголосовало: 0».
- **Свой голос:** «Ваш голос: За · можно сменить», выбранная кнопка выделена. Показывать только
  самому участнику; не кэшировать между пользователями; инварианты тайны (Q-006) не нарушать.
- Итог: число и процент по каждому варианту и простая полоса; кворум одной строкой.
- **«Обсудить в форуме»** — ссылка на сообщение Хранителя в ветке «Вече», если оно
  опубликовано (`poll_announcement_message_id` / `poll_collection_announcement_message_id`).

## 4. Меню

У пункта «Вече» — число вопросов, где участник может сейчас подписать или проголосовать и ещё
не сделал этого. Ноль не показывать.

## 5. Слова

На экране: «вече» и «вопрос». «Предложение» — только в архиве старых записей, «опрос
мнений» — как тип вопроса. Не использовать «круг», «сота», «путь созыва», «режим»,
«перманентное».

## Проверка

Typecheck; ближайшие тесты страниц Вече, обновлённые под новую разметку; тест, что свой голос
виден только самому участнику и не попадает в чужой HTML/RSC; тест, что шаг 6 показывает тот же
порог, который фиксируется при создании; тесты существующих инвариантов тайны и анонимности
проходят без изменений.
