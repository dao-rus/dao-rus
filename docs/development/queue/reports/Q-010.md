# Q-010. Анонимный инициатор

## Сделано

Миграция 049 добавляет public/anonymous по умолчанию public, с DB запретом изменения.
Выбор есть в общей форме подписного и платного созыва. Внутренний FK автора сохранён.
`publicProposal` — серверная проекция вопроса для списков и опроса; ID/имя скрытого автора
не попадают в API, HTML/RSC, ParticipantName, бейджи/индикаторы и общую админку.
Собственное право проверяется через boolean `ownProposalFlags`, без выдачи внутреннего ID:
автор видит «Ваш вопрос» и закрывает свой перманентный опрос.

Защищены и участия самого анонимного инициатора: публичная подпись/открытый голос
не содержат его ID/имени, само участие и выбор учитываются. Другие участники остаются
публичными по правилам Устава; самоподпись в порог не входит. Тайный выбор по-прежнему
не выдаётся. Для открытого опроса скрытый участник отображается без имени.

Анонимное proposal.created имеет NULL actor и allowlist payload; это охраняет DB trigger.
Объявления Хранителя уже содержали только вопрос/ссылку; проверена совместимость.
`darus_visible_book(target,viewer)` скрывает чужой анонимный debit и связь других движений
с вопросом/hold. Личный вид использует ID из session и показывает собственное списание
и ссылку на вопрос. Raw audit primitive не является публичным API; caller-facing книга
использует reader с явным зрителем. Экран раскрытия автора не добавлен.

Форма предупреждает о косвенном раскрытии самим текстом и границе доверия к оператору.
Тексты в interfaceTextFields; backlog и veche-opinion-polls.md обновлены.
