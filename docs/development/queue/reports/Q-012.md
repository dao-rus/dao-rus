# Q-012. Пошаговый созыв и понятный раздел Вече

`/veche/new` состоит из шести серверных GET-страниц: вопрос, кого касается,
голосование, длительность, имя, сводка/созыв. JavaScript для прохождения не нужен,
черновика в БД нет. Значения передаются скрытыми полями; ошибочный ввод возвращается
на соответствующий шаг. Есть номер шага, назад/далее и ссылки изменения из сводки.
Поле своей даты показывается только после выбора этой даты; проверка обязательности
серверная, поэтому без JS можно снова выбрать другой срок.

Сводка показывает действующий max(минимум, ceil(доля × население)), срок подписей,
точную цену, баланс и последствия. Недоступные настройки не показываются; для
настроенного платного созыва с недостаточным балансом кнопка disabled по TASK.md.
Нет города / нет членства / заморозка / общая пауза / выключенный созыв объясняются.
Заморозка ссылается на публичное решение; пауза показывает дату. Финальное создание
остаётся `/api/veche` с прежними create helpers и DB guards. Предварительный расчёт
не резервирует цену: при изменении настроек или населения окончателен snapshot POST.
Пресеты срока задают тот же абсолютный deadline, который поддерживался ранее;
правило окончания сбора при более раннем deadline не менялось.

Главная: заголовок и короткая строка, кнопка созыва или сообщение о выключенном созыве;
группы собирающих подписи / голосующих / завершённых, без пустых групп. Карточки содержат
заголовок-ссылку, статус, аудиторию, тайно/открыто, подписанный срок, прогресс «N из M»,
собственные отметки участия и публичного автора либо «Автор скрыт». Тексты вопросов
в карточках не отображаются. Старые предложения сохранены в свёрнутом архиве;
старая форма убрана, API /api/proposals сохранён. Настройки администратора — кнопка в конце.
Карточки читаются пакетно через publicProposal, без отдельной транзакции на каждый вопрос.

На странице вопроса — крупный статус, подписанные даты; при сборе нет нулевого turnout.
Свой голос читается отдельным scalar helper с participant.id текущей сессии только для
force-dynamic страницы. Общая проекция/API/объявления не получают собственный бюллетень.
Выбранная кнопка отмечена aria-pressed, возможность смены показана только при доступности.
Итог — количество, процент, доступная meter-полоса и строка кворума. Ссылка обсуждения
строится существующим forumMessageLink по сообщению Хранителя и настройке ветки.
Меню считает доступные неподписанные/непроголосованные вопросы, ноль не показывает.
Новые тексты — в interfaceTextFields; описание сводки — в существующем UserText.
