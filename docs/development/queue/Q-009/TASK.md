# Q-009. Вече: пустые вопросы

**Уровень риска:** обычное изменение с миграцией. **Deploy:** да, если миграция только
добавляет. Зависит от Q-006; связь с чеканкой — Q-008.

[Устав](../../../governance/charters/veche.md), п. 9.

## Сделать

1. На опросе — кнопка **«Вопрос пустой»** для участников круга с заполненным городом, кроме
   инициатора. Одна отметка на человека, её можно снять, пока опрос открыт.
2. **Отметки открыты:** видно число и кто отметил. Тайных отметок нет.
3. Порог — доля проголосовавших (настройка в админке). Если при закрытии порог достигнут,
   опрос признан пустым: чеканки за благо нет (Q-008), итог показывает это гласно.
4. **Заморозка права созыва.** Если у автора за последние M дней K опросов признаны пустыми
   (настройки), право созывать замораживается на D дней (настройка). Заморозка видна на его
   профиле и в объявлении в ветке «Вече», если маршрут задан. Никаких скрытых ограничений.
5. По умолчанию заморозка выключена (K = 0).

## Проверка

Тесты: инициатор не отмечает свой опрос; отметка снимается до закрытия; признание пустым
отменяет чеканку; заморозка включается по порогу и снимается по сроку; заморозка видна
публично. Typecheck, миграция на реальной PostgreSQL.
