# Q-008. Вече: тариф и награды

**Уровень риска:** критический инвариант (ledger/rewards, concurrency). **Deploy:** да,
но всё выключено в админке до того, как Ван задаст числа. Зависит от Q-005, Q-006, Q-007.

[Устав](../../../governance/charters/veche.md), п. 4 и 7.

## Тариф (второй путь созыва)

1. Инициатор может созвать опрос сразу, без подписей, заплатив тариф, если хватает баланса.
   Если не хватает — только подписи.
2. Тариф = базовая ставка × множитель круга × число участников круга. Все три — настройки в
   админке; отдельно для соты и для всего ДАО.
3. Тариф списывается при созыве и держится на опросе (механизм Q-005). Не возвращается.

## Плата за внимание

4. При закрытии удержанный тариф делится поровну между проголосовавшими, включая
   «воздержался». Округление до 6 знаков; остаток от округления возвращается инициатору.
5. Если не проголосовал никто — тариф остаётся списанным, раздачи нет.
6. Перманентный опрос: тариф делится между проголосовавшими в первые N дней (настройка, по
   умолчанию 7), раздача — по истечении N дней.

## Чеканка за благо

7. При закрытии, если кворум набран и опрос не признан пустым (Q-009; до Q-009 — только
   кворум), проголосовавшим чеканится сумма из правила награды (`reward_rules`, версионно).
   Одинаково для обоих путей созыва. Сумма — настройка, по умолчанию 0 = выключено.

## Награда организатору за связность

8. Если явка ≥ доли действующих участников ДАО (настройка), инициатор получает чеканку по
   отдельному правилу награды. Не чаще раза в N дней на человека (настройка). По умолчанию
   выключено.

## Не делать

- Переводы между участниками — вне задания (см. Q-005): не реализовывать и не запрещать.
- Награду за подпись и за совпадение с большинством.

## Проверка

Integration tests: тариф не списывается при недостатке баланса; одновременные созывы не
уводят баланс в минус; раздача идемпотентна при повторном закрытии; сумма раздачи + остаток =
тариф; чеканка только при кворуме; лимит награды организатору. Typecheck. Production: только
проверить, что настройки появились и выключены.
