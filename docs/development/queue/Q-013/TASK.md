# Q-013. Вече: участник без города — блокировка с объяснением

**Уровень риска:** малое изменение интерфейса. **Deploy:** да. Права не меняются: по Уставу
(п. 4.1, 5.1) участник без города уже не может созывать, подписывать и голосовать. Меняется
только то, как ему это объясняется.

Решение Вана 2026-10-10: «Устав надо соблюдать; пусть для таких опция вече будет заблокированной»
— чтобы заполнение города стало входом в Вече.

## Сделать

Одна и та же строка (новый ключ `interfaceTextFields`, по умолчанию):
«Вы не указали место жительства — участие в Вече недоступно.» + ссылка «Указать город» на поле
города в профиле. Показывать её везде, где участник без города упирается в блокировку:

1. `/veche` — кнопка «Созвать вече» видна, но неактивна; строка под ней.
2. `/veche/new` — вместо нынешнего «Укажите город в профиле, чтобы созывать вече.»
3. Страница вопроса — вместо кнопок подписи, голоса и «Вопрос пустой» и вместо общего
   `veche.ineligible`, если причина именно в отсутствии города. Для участника с городом вне
   круга вопроса — прежний текст.

Читать вопросы и итоги участник без города может, как сейчас.

## Проверка

Тесты: участник без города видит строку и ссылку на всех трёх страницах; кнопка созыва
неактивна; участник с другим городом видит прежний текст, а не эту строку. Typecheck.
