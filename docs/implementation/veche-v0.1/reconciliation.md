# Вече v0.1 — сверка проектных документов с Уставом и кодом

Дата: 2026-10-09. Нормативный источник по Вече — [Устав созыва вече](../../governance/charters/veche.md);
проектные документы ([концепция](../../governance/anonymous-automatic-veche.md),
[модель v0.1](../../architecture/veche-mvp-v0.1.md), [итерация 0](iteration-0-task.md)) его
дополняют. Ниже — как разрешены расхождения, по [принципу обратимых решений](../../architecture/decision-making-principle.md).

| Вопрос | Решение | Где |
|---|---|---|
| Анонимный инициатор | Принят. Выбор при созыве, потом не меняется; подписи и голоса — по своим правилам | Устав п. 4.8; Q-010 |
| Порог поддержки | Большее из двух: минимум человек (5 для пилота) или доля круга | Устав п. 4.2; Q-011 |
| Фиксация правил при созыве (GovernanceRuleSnapshot) | Принята | Устав п. 4.2; Q-011 |
| Голосование | Остаётся в Ядре: уже построено (Q-006), тайна голоса закрыта тестами; Telegram-опрос не умеет тайного голосования с проверкой права. Telegram — обсуждение и объявления | Устав п. 1.4, 5 |
| Отрицательные сигналы | Открытые отметки «Вопрос пустой» о злоупотреблении, не о несогласии; автоматической приостановки нет; заморозку утверждает вече с правом обжалования | Устав п. 9; Q-009 |
| Подтверждение личности для допуска | Не решено; пока допуск — действующий участник с городом | Устав п. 16 |
| Тариф и награды | Без изменений | Устав п. 4, 7; Q-008 |

Задание [итерации 0](iteration-0-task.md) поглощено очередью: аудит поверхностей утечки автора
входит в Q-010, порог и фиксация правил — в Q-011. Отдельно его не выполнять.
