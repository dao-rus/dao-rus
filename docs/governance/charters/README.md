# Уставы ДАО Русь

Уставы расширительно проецируют [Кодекс](../code.md) на отдельные области жизни ДАО.
Кодекс остаётся кратким каноном; устав описывает, как его пункты применяются в
конкретной механике.

- Устав не изменяет Кодекс и не утверждает его толкований.
- У каждого устава одна действующая редакция; версия, дата и статус указаны в шапке файла.
- Участники обращаются к уставам через ИИ-ангелов: Ангел отвечает на конкретный вопрос
  только по тексту устава и называет пункт; если устав на вопрос не отвечает, Ангел так
  и говорит.
- Пункты нумеруются, чтобы на них можно было ссылаться.
- Один устав — один файл с именем по предмету (`veche.md`, `awards.md`). Версия, статус и
  дата стоят в шапке, а не в имени файла; прежние редакции хранит история git.

  (Наградной устав, п. 8). С чеканкой DARUS не связана.
