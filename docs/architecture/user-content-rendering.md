# Отображение пользовательского текста

> Пользовательский содержательный текст в Core отображается через единый безопасный
> Markdown/autolink renderer. Исходный текст хранится без преобразования; Markdown является
> presentation-layer.

## Реализация

Собственный компактный разбор без зависимостей: `apps/core/src/lib/user-markdown.ts`
строит AST, `apps/core/src/components/user-text.tsx` (`<UserText>`) превращает его в React-дерево.
HTML не генерируется и не сохраняется, `dangerouslySetInnerHTML` не используется. Библиотека не
подключалась: нужно пять конструкций, а собственное дерево исключает raw HTML по построению.

Поддерживается: ссылки `http`/`https` (голые URL и `[текст](url)`), `**bold**`, `*italic*`,
списки `- ` / `* `, переносы строк. Остальное — обычный текст: HTML-теги, заголовки,
изображения, `javascript:`, `data:` и любые иные схемы. Внешние ссылки открываются в новой
вкладке с `rel="noopener noreferrer"`. Стили наследуются от контейнера.

`inline` — вариант без блоков для заголовков и элементов списков.

## Где применяется

Описания и карточки Signals (Exchange, профили, карточка, Angel-подсказки), «О себе»,
комментарии Кодекса, предложения Вече, объявления и сигналы сообществ, сообщения и тексты Relay.

Не применяется: имена и username, названия предложений, ярлыки Signals в списках-ссылках,
системные подписи и тексты интерфейса, уведомления, канонический текст Кодекса, шаблоны
Хранителя, `telegramBio` (импортированные данные), статусы, даты, ключи.

## Превью Signals

Списки Signals (Exchange, Angel-поиск, профили) используют общий `SignalPreview`: одна
ссылка на canonical `/exchange/<id>` растянута на всю карточку, label и description
показываются через `<UserText preview>` (Markdown-ссылки там неинтерактивны), автор — просто
подпись, длинный текст ограничен CSS line-clamp без изменения данных. Полный Markdown и ссылки
на автора — на самой карточке Signal.

## Границы

Share-payload, metadata (OpenGraph), поиск и аудит работают с исходным текстом. Новое
поле со свободным текстом подключается к `<UserText>`; параллельный renderer не создаётся.
