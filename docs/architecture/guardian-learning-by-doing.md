# Хранитель: обучение через действие

Статус: концептуальный принцип; не является заданием на немедленную реализацию.

## Принцип

ДАО «Русь» помогает человеку постепенно осваивать свои возможности через последовательность небольших практических действий. Хранитель сопровождает этот процесс: предлагает следующий необязательный шаг, объясняет его смысл и помогает при затруднениях.

Цель — не формальное прохождение инструкций, а постепенное включение человека в реальные связи и совместную деятельность. Участник самостоятельно выбирает темп и глубину вовлечения.

## Архитектурные ограничения

- Низкий порог входа; Кодекс остаётся постоянным ориентиром.
- Нет обязательного учебного маршрута, экзамена или нового статуса участника.
- Шаги предлагаются по контексту и реальным возможностям человека, без навязчивого давления.
- Рост доверия основан на реальных связях и поведении, а не на прохождении уроков.
- Хранитель помогает действовать, но не подменяет волю участника.

## Возможное применение

При знакомстве с ДАО Хранитель может предложить осмотреть профиль, изучить Кодекс, указать интерес или потребность, откликнуться на запрос либо начать первое совместное дело. Для разработчиков аналогичный подход применим к небольшим задачам в GitHub с обратной связью.

Источник идеи: учебная механика GitHub Learning Lab (пример https://github.com/lauraleap/github-slideshow). Заимствуется принцип пошагового обучения через практику, **не** код или технологическая архитектура этого архивного репозитория.
