# Автоматические сообщества DAO Core (MVP)

Сообщество места определяется тройкой `residence_country`, `residence_type`,
`residence_name` профиля. Сообщество интереса определяется нормализованной меткой
`participant_interests`. Отдельного ручного членства нет: состав пересчитывается
из профилей при открытии `/participants` с соответствующим фильтром. Список
участников сохраняет действующие ограничения каталога: показывает Core
Participants, которые вошли в Core или состоят в основном Telegram-форуме,
и не раскрывает другим пользователям скрытые интересы. Четыре профильных блока
относятся к месту жительства участника;
для других пользователей видны только блоки `public` и `members`.

Лента хранит публикацию в `community_posts`, а размещения — в
`community_post_targets`. Поэтому одна публикация в будущем сможет иметь
несколько сообществ без смены идентичности или дублирования текста. Сейчас
форма создаёт одно размещение. Писать может участник соответствующего
сообщества; удалить публикацию может только её автор. Удаление отмечается
`deleted_at`, а создание и удаление записываются в журнал событий.

Награда за первое место жительства использует `reward_rules` и
`darus_ledger`. Частичный уникальный индекс на `participant_id` запрещает
повторное начисление. Новое начисление выполняется в транзакции сохранения
профиля при переходе от пустого места к заполненному. Миграция начисляет
награду профилям с уже заполненным местом. Для профиля с пустым местом
историческое событие изменения места блокирует награду при повторном
заполнении, поскольку прежние события не сохраняли значение места.

Раздел `/nearby` ссылается на сообщества населённых пунктов через полный фильтр
места жительства в `/participants`. Эти сообщества доступны авторизованным
участникам даже при отключённом общем каталоге. Внизу `/nearby` группа
«Не указавшие» ведёт на `/participants?without_residence=1` — список участников
с незаполненной или неполной тройкой места жительства. Фильтр сохраняется
при поиске и сортировке; применяется тот же критерий видимости участников, что и в каталоге.
Это список, а не новое членство или отдельная сущность сообщества.
