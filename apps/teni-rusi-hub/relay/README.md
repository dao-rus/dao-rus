# Переходник коммутатора (Cloudflare Workers)

Хостинг хаба (HostiMan) не пускает к сайту запросы из дата-центров, а Claude и ChatGPT ходят именно оттуда.
Переходник стоит на Cloudflare: принимает запросы программ (`/api`) и ИИ-ассистентов (`/mcp`, `/mcp/КЛЮЧ`),
держит их в памяти до 25 секунд, а сервер хаба сам забирает их исходящим запросом (`POST /_pull`, раз в минуту
cron `bin/relay-pull.php`, внутри — долгий опрос) и возвращает ответы следующим опросом. Ничего не хранится.

- Адрес: `https://hub.kommutator.workers.dev` (воркер `hub`, поддомен аккаунта `kommutator`).
- Секрет `RELAY_SECRET` (32–128 букв/цифр) — общий для воркера (`wrangler secret put`) и хаба (`bin/set-relay.php`).
- Бесплатный тариф: 100 000 запросов в день, 13 000 GB-s в день для Durable Objects; опрос хаба занимает около 85 % второго.
  При превышении переходник отвечает ошибкой до 03:00 МСК, денег не списывается.

Выкладка: `npx wrangler@4 deploy` в этом каталоге с переменными окружения `CLOUDFLARE_API_TOKEN` (шаблон
«Edit Cloudflare Workers») и `CLOUDFLARE_ACCOUNT_ID`.
